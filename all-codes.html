About expiry dates: Safelite publishes no expiry date for these codes, so this page shows the date each one was last confirmed working instead — October 21, 2026. One code per order. Checkout will not stack two codes, so there is no benefit in collecting the whole list — for a replacement, start with ADDS100; for a repair, start with SAVENOW2026. If a code ever fails, work down the same table.
