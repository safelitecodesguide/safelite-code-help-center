“Promo code is not valid” — what it really means

A rejection feels like a typo problem. Often it is not. Here is the full checklist a help desk would work through, plus the codes that will never work no matter how carefully you type them.

Work through these first

  • The code is dead. Codes stop working without announcements. If a code is not on the confirmed list, check this first — five examples are named below.
  • Wrong service type. Repair-only codes (SAFELITEHEROREPAIR20, WEB15SL) will not apply to a replacement quote, and replacement-only codes will not apply to a repair.
  • You are on the insurance path. The promo field appears there, but the offers exclude insurance claims. Restart the quote as pay-on-my-own to test a code.
  • Commercial or fleet booking. The published offers exclude commercial and fleet services.
  • A second code replaced the first. Checkout keeps one code per order — re-apply the bigger one.
  • A typo. Least common when you copy and paste, but check characters like 0/O and 1/I by pasting from the code tables here instead of retyping.
