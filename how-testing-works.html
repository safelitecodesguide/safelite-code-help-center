How every answer on this site is earned

Coupon sites copy each other. This help center does something slower and more reliable: it tests. Here is the exact method behind every status and answer you have read.

The test, repeated every two days

  1. A standard quote is built on safelite.com (sample: 2022 Toyota Camry, ZIP 30303, pay on my own).
  2. Each tracked code is pasted into the “I have a promo code” field at checkout and the result is recorded.
  3. A code counts as working only if a discount line appears and the total drops by a stated amount. Anything else counts as not working, and the code is named on the dead list.
  4. New candidate codes — from Safelite's own pages and from listings around the web — are tested the same way before they are ever recommended here.
  5. Every page is updated to the latest check date. The current edition reflects October 21, 2026.

Rules this site holds itself to

  • No invented expiry dates. Safelite does not publish expiry dates for these codes, so pages show the last-confirmed date instead.
  • No copied claims. When a listing site says a code is “active” and checkout rejects it, checkout wins — see AAA10SL on the dead list.
  • No percentage shortcuts. 10THANKYOU10 is reported as the dollars it actually removed ($39.08 on the sample), not as a headline “10% off.”
  • No untested prices. Post-code prices are shown only for vehicle-and-code combinations that were actually run.
  • One passing test is not a promise. Results can vary by vehicle, ZIP and service — which is why every page tells you to confirm the discount in your own quote.
