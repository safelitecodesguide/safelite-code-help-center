Applying a promo code on safelite.com

The promo field is easy to miss — it hides behind a small link on the quote screen. Here is the exact path, plus the one confirmation that proves the code worked.

Step by step

  1. Open safelite.com and start a quote: enter your ZIP, your vehicle, and what glass is damaged.
  2. When asked how you are paying, choose pay on my own. The offers on this site are valid when scheduling on safelite.com and paying yourself — they are not valid on insurance claims.
  3. On the quote screen, look near the price summary for the link “I have a promo code.” Tap it and a code field opens.
  4. Paste your code (start with ADDS100 for a replacement, SAVENOW2026 for a chip repair) and apply it.
  5. Confirm before you book: a discount line must appear and the total must drop. No discount line means the code did not work, whatever the site you copied it from promised.
  6. Finish booking while the discount is showing. If the total later changes, the code's confirmation was the number on this screen.

Good to know before you start

  • One code per order. Entering a second code replaces the first — pick the biggest one for your job from the full list.
  • The field also appears in the insurance flow — but per Safelite's terms, codes are not valid on insurance claims. Seeing the field is not the same as the offer applying.
  • Paste, do not retype. A single wrong character is a silent rejection — copy the code from the tables here so characters like 0/O and 1/I cannot trip you up.
  • Sample totals on this site (like $787.63 for a 2022 Camry replacement) are examples from testing, before tax and fees. Your quote will differ.
Code rejected? Do not keep retrying the same code. Check the troubleshooting page — the code may be dead, wrong for your service type, or blocked by the insurance path — then try the next code down the list.
