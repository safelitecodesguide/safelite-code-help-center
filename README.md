# Safelite Code Help Center (Netlify)

Static site — help-center style answers for Safelite promo codes, checkout-tested Oct 21, 2026.

Deploy (owner, from Netlify account): Netlify -> Add new site -> Import an existing project -> connect GitHub -> select this repo (safelitecodesguide/safelite-code-help-center). Build command: leave empty. Publish directory: . (root). Production branch: main. A netlify.toml with these settings is included.

After the site is created, replace YOUR-SITE in canonical tags, sitemap.xml and robots.txt with the real Netlify subdomain.
