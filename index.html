Popular questions

Start typing in the search bar above and this list filters itself.

What is the best Safelite promo code right now?

ADDS100 — $100 off a windshield replacement, the largest saving confirmed at checkout on October 21, 2026. For a chip repair, the best confirmed code is SAVENOW2026 at $25 off.

How do I apply a promo code on safelite.com?

Start a quote, choose “pay on my own,” and on the quote screen tap “I have a promo code.” Paste the code, apply it, and check that a discount line appears and the total drops before you book.

Why did checkout say my code is “not valid”?

The usual reasons: the code has stopped working, it does not match your service (repair-only vs replacement-only), or you are booking through insurance, where codes do not apply. Five widely listed codes — SAVE20SL, GLASS20, RECA35ECJPH2, REPAIR10 and AAA10SL — were rejected in the latest check.

Can I use a promo code with an insurance claim?

No. Safelite's offer terms exclude insurance claims, even though a promo field appears in the insurance booking flow. Codes work when you pay on your own and schedule on safelite.com.

Can I combine two promo codes?

No. Checkout accepts one code per order, so pick the single biggest code for your job — for replacement that is ADDS100, for repair SAVENOW2026.

Is 10THANKYOU10 really 10% off?

Not 10% of the full price. In checkout testing it took $39.08 off a $787.63 replacement quote — about 5%, calculated on a subtotal. It is Safelite's group code for military, AAA, AARP and first responders, and eligibility is checked at the appointment.
